# 「找工作看重什么」穷举 + 企业端可采性审计

> 方法：**先穷举，不做取舍**；再逐项检查企业端能不能采集；最后才决定谁进排序。
>
> 企业端的数据源只有一个：**企业在官网/招聘页上公开写出来的文字**。
> 这条边界决定了后面所有结论。

---

# 第二部分：可采性审计

**判据只有一条：这件事，企业会不会写在公开的招聘页上？**

| 等级 | 含义 |
|---|---|
| ✅ | 招聘页/官网上通常写，能稳定拿到 |
| ⚠️ | 部分企业写，覆盖率低，要碰运气 |
| ❌ | 公开页面基本不写，采不到 |

---

## 1. 钱

| 项 | 判定 | 依据 |
|---|---|---|
| 1.1 起薪高 | ✅ | `salary` 里常有"8-12K"；覆盖率约 45% |
| 1.2 年薪结构 | ⚠️ | "13薪/14薪"常写在薪资后 |
| 1.3 涨薪机制 | ❌ | 几乎不写 |
| 1.4 年终奖 | ⚠️ | 偶尔写"年终奖" |
| 1.5 五险一金 | ❌ | 校招页偶尔提"五险一金"，比例不写 |
| 1.6 补贴 | ⚠️ | 有时写"餐补/交通补贴" |
| 1.7 包吃住 | ⚠️ | 制造业/基层岗位常写 |
| 1.8 加班费 | ❌ | 不写 |
| 1.9 安家费 | ⚠️ | 国企/事业单位校招常写"安家费" |
| 1.10 股权期权 | ⚠️ | 少数科技公司写 |
| 1.11 试用期打折 | ❌ | 不写 |
| 1.12 薪资透明 | ✅ | **有没有写工资本身就是一个信号** |

## 2. 稳定与风险

| 项 | 判定 | 依据 |
|---|---|---|
| 2.1 有编制 | ⚠️ | 事业单位招聘公告会写"事业编制" |
| 2.2 国资背景 | ✅ | `nature` 字段，覆盖率约 80% |
| 2.3 行业稳定 | ✅ | `industry` 字段，约 85% |
| 2.4 公司规模 | ❌ | **契约里没有规模字段，名单里也没有** |
| 2.5 是否上市 | ⚠️ | 企业名含"股份有限公司"可弱推断，不可靠 |
| 2.6 成立年限 | ❌ | 招聘页不写 |
| 2.7 裁员传闻 | ❌ | 不可能写 |
| 2.8 用工形式 | ⚠️ | 少数公告写"劳务派遣"，需警惕 |
| 2.9 试用期 | ❌ | 不写 |
| 2.10 服务期/违约金 | ⚠️ | 部分国企/事业单位写"服务期 5 年" |

## 3. 地域

| 项 | 判定 | 依据 |
|---|---|---|
| 3.1 离家近 | ✅ | 需 `home_city` + `city` |
| 3.2 大城市 | ✅ | 需静态城市分级表 |
| 3.3 生活成本低 | ✅ | 同上表反向用 |
| 3.4 特定城市 | ✅ | `city ∈ region[]` |
| 3.5 落户 | ⚠️ | 少数城市企业写"可落户" |
| 3.6 通勤 | ❌ | 不写具体地址到门牌 |
| 3.7 城市前景 | ❌ | 主观 |
| 3.8 和伴侣同城 | ❌ | 与数据无关 |
| 3.9 不出差 | ⚠️ | 岗位要求里偶写"需长期出差" |
| 3.10 气候适应 | ❌ | 主观 |

## 4. 岗位内容

| 项 | 判定 | 依据 |
|---|---|---|
| 4.1 专业对口 | ✅ | `title + requirements` 语义匹配，约 50% |
| 4.2 兴趣匹配 | ⚠️ | 只能靠方向词近似 |
| 4.3 能学到东西 | ❌ | 招聘页会说"学习机会多"，是套话，不可信 |
| 4.4 内容清晰 | ✅ | **岗位名+职责写得清不清楚，本身就是可测信号** |
| 4.5 有挑战性 | ❌ | 主观 |
| 4.6 有创造性 | ❌ | 主观 |
| 4.7 人际强度 | ⚠️ | 从岗位名可弱推（销售 vs 研发） |
| 4.8 体力消耗 | ⚠️ | "倒班/车间"可弱推 |

# 第三部分：审计结果汇总

## 74 项的分布

| 等级 | 数量 | 占比 |
|---|---|---|
| ✅ 可采，能进排序 | **14 项** | 19% |
| ⚠️ 弱采，只能当加分或提示 | **26 项** | 35% |
| ❌ 采不到 | **34 项** | 46% |

**接近一半的偏好，公开页面根本不写。**

## ✅ 可进排序的 14 项

| 类 | 项 | 信号 |
|---|---|---|
| 钱 | 起薪高 | `salary` 数字 |
| 钱 | 薪资透明 | 有没有写工资 |
| 稳定 | 国资背景 | `nature` |
| 稳定 | 行业稳定 | `industry` |
| 地域 | 离家近 | `city` vs `home_city` |
| 地域 | 想去大城市 | `city` + 城市分级表 |
| 地域 | 生活成本低 | `city` + 城市分级表 |
| 地域 | 特定城市 | `city` vs `region` |
| 岗位 | 专业对口 | `title+requirements` |
| 岗位 | 内容清晰 | 岗位名/职责是否具体 |
| 机会 | 学历够得上 | 岗位要求 vs `degree` |
| 机会 | 招的人多 | `headcount` |
| 机会 | 岗位可选多 | `jobs.length` |
| 其他 | 企业性质 | `nature` |

**只有这 14 项可以参与打分。**

## ⚠️ 26 项弱采

只能做**加分项**或**展示提示**，不能当主权重。例如：
- 有导师带教（"一对一导师"）
- 不用倒班（出现"倒班"就减分）
- 能接受出差（出现"适应出差"就减分）
- 可落户、有安家费、包吃住

**做法：命中加分，不命中不扣分。** 因为"没写"≠"没有"。

## ❌ 34 项采不到

其中 21 项属于「企业内部运作」（文化、领导、加班、涨薪、裁员），公开页面永远不会有。

**这 21 项不能扔，要转成现场要问的问题：**

| 采不到的 | 转成现场问什么 |
|---|---|
| 不加班 | "这个岗位平时几点下班？周末要加班吗？" |
| 不容易裁员 | "这个部门近两年有调整吗？" |
| 收入涨得快 | "入职后一般多久调一次薪？" |
| 能学到东西 | "新人前半年主要做什么？有人带吗？" |
| 晋升快 | "干得好的话，几年能到一个什么位置？" |
| 团队氛围 | "团队现在多少人？都是什么背景？" |
| 公司够大 | 看展位规模、看排队的人 |

**这 7 个问题印成一页纸，就是学生站在摊位前该问的话。**
——这比硬塞进排序有意义得多。

# 第四部分：问卷该问什么

**结论：问卷要问全部 74 项里的"偏好"，但只有 14 项进排序，7 项转现场问，其余做展示。**

## 问卷设计（按可采性分三段）

### 第一段：给「能算」的 14 项打分（进排序）

> **请给下面这些维度分配 100 分**
> （这 14 项是企业数据能算出来的，你最看重哪几项？）

| 维度 | 说明 |
|---|---|
| 起薪 | 月薪高低 |
| 薪资透明 | 招聘页写不写工资 |
| 国资背景 | 国企/央企/事业单位 |
| 行业稳定 | 行业本身稳不稳 |
| 离家近 | 在老家或附近 |
| 大城市 | 一线/新一线 |
| 生活成本低 | 二三线，房租低 |
| 想去某个城市 | 有明确目标城市 |
| 专业对口 | 岗位和学的相关 |
| 岗位清晰 | 招什么、干什么写得明白 |
| 学历够得上 | 别白投 |
| 招的人多 | 机会大 |
| 岗位可选多 | 可挑 |
| 企业性质 | 我偏好的那类 |

**合计 100 分 → 直接就是匹配端权重。**

### 第二段：问「采不到但重要」的 21 项（转现场提问）

> **下面这些企业招聘页不会写，但对你很重要。选 3 个你最在意的，我们会写进你的现场提问清单。**

- 加不加班 / 能不能双休
- 会不会裁员
- 涨薪快不快
- 能不能学到东西
- 有没有导师带
- 晋升快不快
- 团队氛围
- 领导风格
- 出差多不多
- 有没有落户

**这 3 个 → 生成现场提问卡。** 不参与排序。

### 第三段：现场行为（验证假设，不打分）

同 v1 的 D/E 段。

---

## 一句话总结

> **74 项里，14 项能算、26 项能当加分、34 项算不了。**
> 能算的进排序，算不了的变成学生现场要问的话。
> 而不是硬凑出来一堆「未知」。
