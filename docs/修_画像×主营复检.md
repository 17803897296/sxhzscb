# 修_画像×主营复检.md

2026-11-17 用户定口径：命中不能只看「岗位名 ↔ 意向岗位」的字面，还要看
「**企业主营业务 + 岗位名**」是否对得上「**意向岗位 + 专业**」。
反面案例：金融公司的「管培生」 × 物流专业学生选的「管培生」——字面全同，
但金融公司培养不出物流方向。

## 新模块 `ent_tools/biz_recheck.py`

确定性规则（无需模型），前端 JS 镜像同源（`fair_report_js.BIZ_FIELDS`）：

- **学生方向词** = 专业所属领域词表 + 每个意向剥掉通用词后的核心词 + 该领域词表。
  领域词表 13 个领域（物流供应链 / 化学化工材料 / 机械制造 / 电气自动化 /
  电子信息 / 计算机软件 / 金融财会 / 土木建筑 / 医学生物 / 食品 / 能源环境 /
  教育 / 设计创意 / 商贸管理），每领域分强词（一票通过）与弱词（不参与主营判定）。
- **明确命中复检**（`filter_real`）：意向或岗位名带方向词 → 放行（具体意向的
  核心词天然在方向词表里）；否则主营强词一票。闸门只咬「全通用意向（管培生 /
  储备干部）× 字面同名岗位」的组合——真实岗位公告是硬证据（有就是有），
  主营判定只兜方向缺失的一类。
- **推断命中复检**（`filter_infer`）：推断岗名是模型按画像猜的，不能自证方向
  —— 主营文本必须出现**强词**；主营为空 / 纯「未知」一律不标（没有业务依据
  就不该推断）。

## 三次翻车与修正（都在测试流程里抓到）

1. **「零售金融」误触发**：「零售」原是物流强词，金融公司的「零售金融」
   被误判成商贸零售证据 → 弱词不参与主营判定。
2. **「安全生产」误触发**：节能集团的主营是网页导航垃圾（「主营业务 安全生产
   节能期刊…」），栏目标题里的实词误触发强词 → `_BIZ_JUNK_PHRASES` 先剔再匹配。
3. **「贸易+商贸」同义词凑数**：奕兴格商贸 merge 后 industry=贸易、主营含
   「商贸」，曾靠两个同族弱词过闸 → 主营判定收紧为强词一票制。

## 集成点

- `fair_bridge._evidence`：`real` 计算后过滤，被拦的对转现场待问
  （`asks`，kind="biz"，理由写明主营 vs 方向为何对不上）。
- `fair_bridge.build` 循环：`_infer_pairs` 构建后按 `biz_text_of(name, c)` 过滤。
- `fair_report_js`：换画像 / 自定义画像的本地重算路径镜像同一规则
  （`miBizKw` / `miBizOkReal` / `miBizOkInfer`）；当前画像路径直接采信
  后端已复检过的 `intent_matches_backend` / `infer_matches_backend`。

## 测试流程（用户定的，可复跑）

`python _test_biz_recheck.py --profile logistics|chemical`
提交完全不同的画像 → 等重算 → 输出全部命中对 + 企业主营上下文，逐条核对。

## 效果（物流管理画像：管培生/物流专员/供应链专员/仓储管理员）

- 基线：明确 8 对 + 推断 29 对。推断里 11 对不合理：教育出版、IT 云计算、
  通信铁塔、房地产集团、空主营、网页垃圾文本、微型环保咨询、家电商贸等
  推断「物流专员」。
- 复检后：明确 8 对**零误伤**（全部带方向词或主营对口），推断 29 → 18 对
  （不合理项全部拦截）。
- 化工画像回归：明确 30 对零误伤；推断 40 → 39（广告分析软件公司靠
  「分析」推断「化工销售工程师」被拦）。

## 已知残余

- 奕兴格商贸在化工画像下仍推断「化工销售工程师」：「金属材料」触发化学
  领域强词「材料」，而「材料」是中电科55所「半导体材料」这类好案例的
  承重词，不宜降级。1 例残余，接受。
- 国动铁塔（有通信装备制造板块）、上成生物（研发生产销售）的物流推断
  属边界合理，保留。
